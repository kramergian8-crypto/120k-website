Positions-Sender

Diese Seite auf einem Handy offen lassen, das dich per GPS live verfolgt. Schickt die Daten direkt an die Website — kein eigener Server nötig. Bildschirm nicht sperren.
Als App-Symbol installieren: unten in Safari auf das Teilen-Symbol tippen → „Zum Home-Bildschirm". Danach öffnet sie sich wie eine echte App, ohne Adressleiste.
Musik während des Laufens: am besten über das Kontrollzentrum/die Sperrbildschirm-Steuerung bedienen, nicht über die Musik-App selbst wechseln — sonst pausiert iOS diese Seite im Hintergrund und das Senden stoppt kurz.

Zugang

Repository ist 120k-live (nicht 120k-website). Wie du den Token erstellst, steht in LIESMICH.txt. Er bleibt nur auf diesem Gerät gespeichert und wird nie auf die Website hochgeladen.

GPS

Der Kilometerstand wird laufend gespeichert und übersteht ein Neuladen oder einen Absturz. Vor einem neuen Lauf hier zurücksetzen, sonst zählt er den alten Stand weiter.

Puls (optional)

Braucht einen separaten Bluetooth-Brustgurt (Polar, Garmin, Wahoo o.ä.) und Android + Chrome. Auf dem iPhone geht das technisch nicht — Apples Safari lässt das nicht zu. Die Suunto-Uhr selbst wird hierfür nicht genutzt.
